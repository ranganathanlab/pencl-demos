PenCL was trained on 45 million text-protein pairs, all in a single annotation format. The result: it only understands SwissProt syntax. The vocabulary problem

PenCL recognizes keywords, not meaning

The current PenCL text encoder (PubMedBERT) was fine-tuned on SwissProt annotations — field-prefixed text in a uniform format. It learned to extract protein identity from this specific vocabulary: "SH3 domain," "osmosensor," "HOG pathway." When the same biology is described in different words — "proline-recognition signaling module," "detects changes in external solute concentration," "high-osmolarity glycerol MAP kinase cascade" — PenCL maps it to a different, less informative region of embedding space.

What PenCL sees today

PROTEIN NAME: Sho1. FUNCTION: Plasma membrane osmosensor. LINEAGE: Saccharomyces cerevisiae.

→ Maps to protein-informative z_c region

What PenCL can't parse

A yeast transmembrane protein whose beta-barrel signaling module binds its downstream MAP kinase kinase to activate osmotic stress responses.

→ Maps to uninformative z_c region

Tier 3 of the corpus augmentation generates two natural language descriptions per protein — written in genuinely different scientific vocabulary — so that PenCL learns to extract biological meaning regardless of how it is expressed.

Two complementary perspectives

Each protein gets a molecular description and a structural description

For each of the 569,516 SwissProt proteins, the Claude Sonnet batch API generates two descriptions that approach the same biology from different angles:

Tier 3a — Molecular / cellular / organism

What does this protein do in its biological context? Its catalytic activity, its role in cellular pathways, its tissue distribution, its organism. Uses the language of biochemistry and cell biology.

Tier 3b — Structure / evolution

What does this protein look like and where did it come from? Its fold, its domain architecture, its evolutionary origin, its relationship to other family members. Uses the language of structural biology and evolution.

Both descriptions convey the same biological identity but in different vocabularies and from different intellectual frameworks. PenCL's contrastive loss sees all three texts (SwissProt original + Tier 3a + Tier 3b) paired with the same protein sequence, and learns that they should map to the same zc embedding.
